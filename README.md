🍔 Menu Mamãe Lanches

Menu Mamãe Lanches é um sistema completo de cardápio digital interativo desenvolvido em Python com Flet, perfeito para lanchonetes e deliveries mostrarem seus produtos de forma moderna e organizada.

⚡Recursos Principais⚡

🍟 Cardápio Organizado: Categorias bem definidas (Lanches, Bebidas, Porções, etc.)
💰 Preços Atualizáveis: Valores dinâmicos e fáceis de modificar
📱 Interface Responsiva: Funciona perfeitamente em desktop e mobile
🎨 Design Atraente: Cards modernos com imagens e descrições
🔍 Busca Inteligente: Procure rapidamente por qualquer item
🛒 Carrinho de Compras: Adicione e gerencie seus pedidos
📞 Contato Direto: WhatsApp integrado para pedidos e feedback.

🎮 Como Usar
Execute o app: python cardapio.py
Navegue pelas categorias usando os botões
Busque itens na barra de pesquisa
Adicione ao carrinho clicando nos produtos
Finalizar pedido pelo próprio app que tem outra interface integrada para o gerenciamento desses pedidos.

🛠 Tecnologias Utilizadas

• python
• flet
• psycopg
• PostgreSQL 

🚀 Instalação Rápida

Copy code
# Clone o repositório
git clone https://github.com/SHERLON20/menu_mamae_lanches.git
cd menu_mamae_lanches

# Instale as dependências
pip install flet

# Execute o cardápio
python cardapio.py
